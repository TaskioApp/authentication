## 🚀 Installation

In your Laravel project's `composer.json`, add the following:

```json
"repositories": [
    {
        "type": "vcs",
        "url": "https://github.com/Taskio/authentication"
    }
]
"require": {
    "taskio/authentication": "*"
}
```

Then run:

```bash
composer update
```
